- ADR-001: Model - Google TimesFM (Time-series Foundation Model) for zero-shot time-series
  forecasting with multi-horizon quantile outputs (10th, 50th, 90th percentiles).
- ADR-002: Dashboard Frontend - Sleek, modernistic, responsive dark-mode trading UI
  inspired by Bloomberg Terminal / TradingView / Linear aesthetic, featuring interactive
  canvas/SVG charting, horizon selection, live indicators, and uncertainty visualization.
- ADR-003: Backend Architecture - FastAPI for lightweight, high-performance async API
  serving TimesFM predictions, ticker history, and backtesting metrics.
- ADR-004: Value-at-Risk Engine - Integrated engine/risk_engine.py combining parametric
